Voglio collegare il parsing delle fatture al `pendingInvoiceStore` perché il Magazzino veda le righe.

1. Crea un nuovo file `services/invoiceImportService.ts` (o usa quello esistente se già c’è) con questo contenuto:

```ts
import { parseInvoiceXml } from '../utils/xmlImportService';
import { pendingInvoiceStore, ItemCategory } from '../pendingInvoiceStore';
import { classificaRiga } from '../utils/autoCategorizationService';

export async function importInvoiceToPending(xmlString: string) {
  const parsed = parseInvoiceXml(xmlString);

  const pendingLinesInput = parsed.lineItems.map(line => {
    const categ = classificaRiga(line.description);

    const detectedCategory: ItemCategory =
      (line.itemType as ItemCategory) || 'altro';

    return {
      invoiceNumber: parsed.documentNumber,
      invoiceDate: parsed.documentDate,
      supplierName: parsed.supplier?.denomination || 'Fornitore',
      lineNumber: line.lineNumber,
      description: line.description,
      quantity: line.quantity,
      unitPrice: line.unitPrice,
      totalPrice: line.totalPrice,
      unitOfMeasure: line.unitOfMeasure,
      vatRate: line.vatRate,
      detectedCategory,
      assignedCategory: detectedCategory,
      categoria: categ.categoria,
      sottoCategoriaUtenza: categ.sottoCategoriaUtenza,
      isProcessed: false,
      processedAt: undefined,
    };
  });

  await pendingInvoiceStore.savePendingLines(pendingLinesInput);
}
```

2. Trova il punto dove ora importo le fatture XML (dove viene chiamato `parseInvoiceXml(xmlString)`) e cambia la logica così:

- invece di usare solo `parseInvoiceXml`, chiama:

```ts
import { importInvoiceToPending } from '../services/invoiceImportService';

await importInvoiceToPending(xmlString);
```

3. Assicurati che, dopo questa modifica, la schermata “Classificazione Righe / Magazzino” usi `pendingInvoiceStore.getPendingLines()` o `getCategoriaSummary()` senza altri filtri che svuotano la lista.
